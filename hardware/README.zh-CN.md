# 硬件

中文 | [English](README.md)

当前硬件版本是一块 **Seeed XIAO nRF54LM20A 的载板**。模块本身提供 MCU、射频、
3.3V 供电、充电与电量计；载板承载 PAW3395 传感器、微动、编码器、I²C 按键扩展与天线。

## 目录内容

| 路径 | 说明 |
| --- | --- |
| `easyeda/Board1.epro2` | 嘉立创EDA专业版主板工程 —— 原理图与 PCB layout |
| `easyeda/SideKeys.epro2` | 侧键小板工程 —— 原理图与 PCB layout |
| `../docs/` | 设计说明，以及早期 nRF52840 原型的归档文档 |

嘉立创EDA专业版工程是原理图与 PCB 的**唯一事实来源**。Gerber、BOM 与坐标文件
都应从该工程导出，不要手工另存修改。

## 元件选型

工程里的按键微动与编码器**只是借用封装**，不是实际型号。实际装配的元件为：

| 位置 | 元件 |
| --- | --- |
| 左右按键 | 欧姆龙 **D2FP-FN2** 光微动 |
| 中键 | 华诺 HUANO **7.8mm 绿点长直脚**微动 |
| 编码器 | **TTC 9mm 金轮** |
| 侧键 | 两颗 华诺 HUANO **两脚右弯带定位柱** 侧键微动 |

同一段说明也写进了两个工程的 `description` 字段，打开工程后可在工程信息面板看到。

## 打开工程

1. 安装 **嘉立创EDA专业版**。
2. `文件 → 打开`，选择 `easyeda/` 下的 `.epro` 工程文件
   （若拿到的是 `.zip` 导出包，用 `文件 → 导入`）。
3. 打开原理图与 PCB，下单前先执行 `设计 → 检查DRC`。

## 打样与贴片

工程按嘉立创工艺设计，下单前请确认：

- 重新跑一遍 DRC，并核对叠层设置。
- Gerber、BOM、坐标文件必须来自**同一个工程版本**。
- 复核 PAW3395 供电：**`VDD` = 1.9V，`VDDIO` = 3.3V**。绝对不要给 `VDD` 上 3.3V，
  会超出绝对最大额定值烧毁传感器。
- SPI 走线尽量短，天线净空区不要铺铜。
- 对照 [`firmware_nrf54lm20a/app.overlay`](../firmware_nrf54lm20a/app.overlay) 核对引脚，
  固件是按这套接线写的。

该许可独立于本仓库的 MIT 协议。再分发模型或售卖打印件时请保留两位作者的署名。

载板就是按这个外壳设计的，原版 PCB 可直接装入，无需修改模型。如果改动了 PCB，
打印前请复核外壳内部间隙（传感器高度、微动柱、电池仓、USB 开孔）。
