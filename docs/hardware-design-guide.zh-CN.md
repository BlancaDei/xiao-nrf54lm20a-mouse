### 1.3 电源引脚连接

| nRF52840引脚 | 功能 | 连接 |
|-------------|------|------|
| VDD | 电源(1.7-3.6V) | ← 3.3V电源 |
| VDDH | 高压电源 | ← 3.3V电源 |
| VSS | 接地 | ← GND |
| DEC1 | 去耦 | ← 100nF → GND |
| DEC2 | 去耦 | ← 100nF → GND |
| DEC3 | 去耦 | ← 100nF → GND |
| DEC4 | 去耦 | ← 10μF → GND |

### 1.4 晶振电路

**32.768kHz RTC晶振：**
```
P0.00 (XLFXL1) ──┤├── 32.768kHz ├──┬── P0.01 (XLFXL2)
                 │  晶振         │
                 └─────┤├────────┘
                      │  │  (可选: 2×12pF电容到GND)
```

**32MHz RF晶振：**
```
P0.02 (XTAL1) ──┤├── 32MHz ├──┬── P0.03 (XTAL2)
                │   晶振      │
                └────┤├──────┘
                     │  │  (可选: 2×12pF电容到GND)
```

### 1.5 下载/调试接口

| 引脚 | 功能 | 说明 |
|------|------|------|
| P0.06 | SWDCLK | 调试时钟 |
| P0.07 | SWDIO | 调试数据 |
| P0.08 | SWDIO | (备选) |
| RST | RESET | 复位信号(10kΩ上拉) |

```
┌─────────────────┐
│   DEBUG接口     │
├─────────────────┤
│ 1. VCC 3.3V    │
│ 2. SWDCLK ←── P0.06
│ 3. GND         │
│ 4. SWDIO ←── P0.08
│ 5. GND         │
│ 6. RST ←── 10kΩ上拉 → VCC
└─────────────────┘
```

## 📐 PCB布局布线指南

### 7.1 关键布局原则

1. **晶振布线**：32MHz晶振尽量靠近nRF52840，线宽3-5mil
2. **天线走线**：50Ω特性阻抗，微带线宽度约15-20mil
3. **电源滤波**：去耦电容尽量靠近芯片电源引脚
4. **分区布局**：数字区、射频区、电源区分开

### 7.2 推荐PCB叠层

- 4层板设计：
  - L1: 信号层 (Top)
  - L2: 地平面
  - L3: 电源平面
  - L4: 信号层 (Bottom)

### 7.3 射频走线规格

```
┌─────────────────────────────────────┐
│           50Ω RF走线               │
├─────────────────────────────────────┤
│  板材: FR-4 (εr = 4.2)             │
│  铜厚: 1oz (35μm)                  │
│  介质厚度: 0.3mm (4层板L1-L2)      │
│  走线宽度: 18mil (约0.46mm)        │
│  走线长度: 尽量短 (<10mm)           │
│  间距: 远离其他信号线 >3W          │
└─────────────────────────────────────┘
```

## 📝 嘉立创EDA操作步骤

### 8.1 创建新项目

1. 打开嘉立创EDA标准版
2. 点击「文件」→「新建」→「工程」
3. 填写项目名称: `Wireless_Mouse_Motherboard`
4. 选择保存位置
5. 点击「确定」

### 8.2 添加元器件库

1. 点击右侧「库」面板
2. 搜索「nRF52840」
3. 如没有找到，下载Nordic官方嘉立创EDA库
4. 同样方法添加 PAW3395, 其他器件

### 8.3 原理图绘制步骤

**步骤1: 放置nRF52840核心**
1. 从库中拖拽nRF52840-QFAA到画布
2. 放置晶振32.768kHz和32MHz
3. 放置去耦电容(100nF × 8)
4. 放置10μF滤波电容

**步骤2: 绘制微动开关电路**
1. 放置D2FP-FN2光微动符号(或创建新符号)
2. 放置10kΩ上拉电阻
3. 连接GPIO引脚

**步骤3: 绘制传感器电路**
1. 放置PAW3395DM-T6QU
2. 连接I2C总线(SDA/SCL)
3. 放置上拉电阻4.7kΩ

**步骤4: 绘制天线电路**
1. 放置匹配元件(C1, C2, L1, L2)
2. 连接RF走线
3. 标注天线接口

**步骤5: 绘制电源电路**
1. 放置电池插座
2. 放置拨动开关
3. 放置稳压器及电容

### 8.4 PCB布局建议

1. **鼠标外形**: 参考50mm × 80mm标准鼠标外形
2. **传感器位置**: 鼠标中心稍偏上
3. **电池位置**: 鼠标后半部分
4. **天线位置**: 鼠标后部/顶部
5. **按键微动**: 对应按键位置下方
